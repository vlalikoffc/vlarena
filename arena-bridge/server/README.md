# arena-bridge server

Локальный HTTP-сервер, выполняющий команды по запросу расширения.
Только встроенные модули Node.js — `npm install` не нужен.

## Запуск

```bash
node index.js                    # 127.0.0.1:7842
node index.js --port 7843        # другой порт
node index.js --workdir C:\proj  # рабочая папка по умолчанию
node index.js --config D:\ab.json
node index.js --print-token
```

При первом запуске создаётся `config.json` с токеном (права `600` на POSIX).
Конфиг читается один раз при старте; изменения, сделанные через popup
(`PUT /config`), сразу применяются в памяти и сохраняются в файл.

## Файлы

| Путь | Назначение |
|---|---|
| `config.json` | порт, токен, workdir, allowlist/denylist, лимиты |
| `~/.arena-bridge/out/*.log` | файлы вывода команд |
| `~/.arena-bridge/history.json` | последние 200 записей истории |

## Политика выполнения

Порядок проверок для команды `cmd`:

1. **denylist** — регулярные выражения по всей строке (регистронезависимо).
2. **shell-метасимволы** — `>`, `<`, `` ` ``, `$(`, `${` (если
   `allowShellMetacharacters: false`). Допускается `2>&1`.
3. **allowlist** — команда разбивается по `&&`, `||`, `;`, `|`, `&`, `\n`;
   имя программы **каждого** сегмента должно быть в `allowedCommands`.
4. **путь к программе** — если в имени есть разделитель пути, он должен быть
   внутри `allowedRoots` или `allowedProgramPaths`.
5. **cwd** — должен быть внутри `allowedRoots`.

Имя программы сравнивается по базовому имени без расширения
(`C:\tools\mvn.cmd` → `mvn`), регистр игнорируется.

## Лимиты

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `maxOutputBytes` | 24 000 000 | меньше лимита вложений arena.ai (25 МБ) |
| `execTimeoutMs` | 300 000 | 5 минут; по истечении процесс убивается |
| `previewLines` | 40 | строк в предпросмотре ответа |
| `historyLimit` | 200 | записей в `history.json` |

При превышении `maxOutputBytes` процесс останавливается, а результат помечается
`truncated: true`.

## Тесты

```bash
npm test          # node --test: 20 тестов (политика + HTTP-маршруты)
```

Тесты поднимают сервер на случайном порту с временным `stateDir` и не требуют
сети/зависимостей.
