# Селекторы и устойчивость к DOM arena.ai

## Что реально используется

| Задача | Селектор | Комментарий |
|---|---|---|
| Поиск блоков команд | текстовые узлы, содержащие `<<<LOCAL_CMD>>>` (`TreeWalker`, `NodeFilter.SHOW_TEXT`) | не зависит от классов и разметки |
| Контейнер блока | наименьший предок, чей `textContent` содержит `<<<LOCAL_CMD>>>` и `<<<END>>>` | обычно `<pre>`/`<code>` сообщения |
| Поле вложений | `input[type="file"]` | приоритет — тот, у кого `accept` включает `text/plain`, `text/*`, `.txt` или `.log`; иначе первый найденный |
| Кнопка «прикрепить» | `button, [role="button"], a[href="#"]`, текст/aria-label по regex `/attach\|upload\|прикреп\|файл\|file\|paperclip\|скреп/i` | используется только если `input[type=file]` не найден |
| Поле ввода сообщения | не требуется | расширение не вставляет текст в чат |
| Кнопка отправки | не требуется | автоотправка сознательно не реализована |

Расширение **не использует** хешированные классы вида `.css-1a2b3c`, `data-testid`
и любые другие «магические» атрибуты: они меняются при каждой сборке фронтенда.

## Правила, которым следуют селекторы

1. **Текстовые маркеры вместо структуры.** Блок `<<<LOCAL_CMD>>>…<<<END>>>` —
   единственный контракт между моделью и расширением.
2. **Поиск от содержимого.** Сначала находим узел с маркером, потом поднимаемся
   вверх, а не пытаемся угадать контейнер сообщения.
3. **Дедупликация через `data-ab-processed`.** Один и тот же контейнер не
   обрабатывается дважды (иначе появились бы дубли панелей при каждом скане).
4. **`MutationObserver` + `setInterval`.** SPA подгружает ответ модели постепенно;
   observer ловит добавление узлов, таймер — страховка от «тихих» обновлений
   (например, изменение `innerHTML` целиком).
5. **Минимум правок в DOM.** Расширение только **добавляет** панель после
   найденного блока, ничего не удаляет и не переписывает — это снижает риск
   сломать разметку чата.

## Точки, которые придётся чинить, если arena.ai поменяет вёрстку

| Симптом | Где чинить |
|---|---|
| Блок находится, панель вставляется не туда | `insertPanel()` в `content.js` |
| Файл не прикрепляется | `findFileInput()` / `setFilesToInput()` в `content.js` |
| Кнопка отправки не находится | функция не используется — отправка ручная |
| Классы/структура изменились | ничего менять не нужно: поиск текстовый |

## Проверка после правок

```js
// в консоли arena.ai: сколько панелей вставлено
document.querySelectorAll('[data-ab-panel]').length;
// сколько найдено маркеров
document.body.innerText.split('<<<LOCAL_CMD>>>').length - 1;
```
