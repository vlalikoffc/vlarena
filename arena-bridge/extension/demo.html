arena-bridge — превью

Так выглядит блок с локальной командой и панель расширения в чате arena.ai.

Соберём проект и проверим, что всё компилируется:

<<<LOCAL_CMD>>>
mvn -q -o clean package
<<<END>>>
arena-bridge · выполнить на вашем ПК
mvn -q -o clean package

      

    


    

      Панель появляется под блоком <<<LOCAL_CMD>>>, требует двух кликов
      («Выполнить локально» → «Подтвердить выполнение»), показывает exit code и превью вывода,
      а файл out-*.log можно прикрепить к чату одной кнопкой.
